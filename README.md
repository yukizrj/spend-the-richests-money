# 花掉首富的钱！

一个原生微信小程序限时花钱竞速游戏：玩家需要在 45 秒内尽可能多地花掉马斯克的财富，并按当日支出金额排名。

## 当前规则

- 初始财富：`$714.2B`
- 赚钱速度：`$2,180,000 / 秒`
- 挑战时间：`45 秒`
- 计分方式：倒计时结束时，实际支出越高，排名越靠前
- 商品机制：六大品类、42 件商品，覆盖 `$5` 到 `$137.5B` 的完整价格梯度；低于十亿美元的商品原则上不限量，稀缺藏品与高价商品保留有限库存
- 随机决策：购买部分大型资产时可能触发隐藏事件；答题期间倒计时与收入暂停，选择后随机产生一次性盈利或亏损，事件盈亏不计入排行榜支出
- 排行榜：默认使用本机当日成绩；部署云函数后自动切换为全服今日榜

规则参数位于 `pages/index/index.js` 顶部的 `CHALLENGE` 对象中。

赚钱速度依据 Forbes 对 SpaceX IPO 给马斯克带来的约 1880 亿美元单日账面增幅折算并取整。它表示资产估值增长速度，不是工资或现金收入。

## 全服排行榜

1. 将项目 AppID 换成正式小程序 AppID，并开通微信云开发。
2. 在云数据库中新建 `daily_scores` 集合。
3. 在开发者工具中右键 `cloudfunctions/leaderboard`，选择“上传并部署：云端安装依赖”。
4. 重新编译后，排行榜会从“本机今日榜”自动切换为“全服今日榜”。

## 运行

使用微信开发者工具导入本目录即可。当前 `appid` 使用 `touristappid`，正式发布前请替换为自己的小程序 AppID。
